# Требования

Перед установкой убедитесь, что сайт соответствует требованиям.

## Платформа

| Параметр | Минимум | Рекомендуется |
|---|---|---|
| 1С-Битрикс | 22.0 | Последняя стабильная |
| Редакция | Малый бизнес | Бизнес / Энтерпрайз |
| PHP | 7.4 | 8.1+ |
| MySQL | 5.7 | 8.0 |

## Модули Битрикс

- `sale` — модуль интернет-магазина
- `catalog` — каталог товаров
- `iblock` — информационные блоки

::: tip Для клиентов
Если не уверены — передайте эту страницу разработчику или обратитесь в команду SOK.
:::
