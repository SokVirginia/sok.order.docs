# Установка

## Шаг 1. Скопируйте файлы модуля

```
/local/modules/sok.order/
```

::: tip
Использование `/local/` гарантирует, что файлы не будут перезаписаны при обновлении.
:::

## Шаг 2. Установите через админку

1. **Marketplace → Установленные решения**
2. Найдите **SOK: Оформление заказа** → Нажмите **Установить**

## Шаг 3. Подключите шаблон

```
/local/templates/ВАШ_ШАБЛОН/components/bitrix/sale.order.ajax/sok.order/
```

```php
$APPLICATION->IncludeComponent(
    'bitrix:sale.order.ajax',
    'sok.order',
    ['PERSON_TYPE_ID' => '1']
);
```

## Шаг 4. Проверьте установку

Откройте страницу оформления заказа. Если форма отображается — установка успешна.

::: warning
При ошибках — **Настройки → Журнал событий**.
:::
