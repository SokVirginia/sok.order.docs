# Что такое модуль

**SOK: Оформление заказа** — модуль для 1С-Битрикс, который расширяет стандартный процесс оформления заказа.

## Из чего состоит модуль

### 1. Шаблон компонента `bitrix:sale.order.ajax`

Кастомный шаблон переопределяет стандартный компонент Битрикс без правки ядра платформы.

### 2. Кастомизация бизнес-логики через события

Дополнительная логика подключается через `AddEventHandler`. Модуль не изменяет стандартные файлы и совместим с обновлениями.
