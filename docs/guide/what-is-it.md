# Что такое модуль

**SOK: Оформление заказа** — это модуль для платформы 1С-Битрикс, который расширяет стандартный процесс оформления заказа в интернет-магазине.

## Из чего состоит модуль

Модуль включает два ключевых компонента:

### 1. Шаблон компонента `bitrix:sale.order.ajax`

Кастомный шаблон переопределяет стандартный компонент Битрикс, отвечающий за страницу оформления заказа. Это позволяет полностью контролировать внешний вид и поведение формы без правки ядра платформы.

### 2. Кастомизация бизнес-логики через события

Дополнительная логика подключается через механизм событий Битрикс (`AddEventHandler`). Это безопасный способ расширения функциональности — модуль не изменяет стандартные файлы платформы и совместим с обновлениями.

## Что умеет модуль

- Переопределяет шаблон страницы оформления заказа
- Добавляет бизнес-логику через обработчики событий `sale`
- Сохраняет совместимость с обновлениями Битрикс
