# Настройка шаблона

После установки модуля вы можете настроить внешний вид и поведение шаблона.

## Структура шаблона

```
sok.order/
├── template.php          — основная разметка формы заказа
├── style.css             — стили компонента
├── script.js             — JS-логика на клиенте
├── result_modifier.php   — модификация данных перед рендером
└── lang/
    └── ru/
        └── template.php  — языковые фразы
```

## Переменные шаблона

Основные переменные, доступные в `template.php`:

| Переменная | Описание |
|---|---|
| `$arResult` | Массив данных заказа (свойства, доставки, оплаты) |
| `$arParams` | Параметры компонента |
| `$arPersonTypes` | Типы плательщиков |
| `$arDeliveryList` | Список служб доставки |
| `$arPaySystemList` | Список платёжных систем |

## Кастомизация стилей

Переопределяйте стили в файле `style.css` шаблона, не трогая стандартные файлы Битрикс:

```css
/* Пример: изменение цвета кнопки оформления заказа */
.order-button {
    background-color: #e63946;
    color: #fff;
}
```

## Языковые фразы

Все текстовые строки вынесены в языковые файлы. Для изменения текстов отредактируйте `/lang/ru/template.php`:

```php
$MESS['SOK_ORDER_SUBMIT_BUTTON'] = 'Оформить заказ';
$MESS['SOK_ORDER_DELIVERY_TITLE'] = 'Способ доставки';
```
