# Установка

## Шаг 1. Получите файлы модуля

Скопируйте папку модуля в директорию `/local/modules/` вашего сайта:

```
/local/modules/sok.order/
```

::: tip
Использование `/local/` вместо `/bitrix/` гарантирует, что файлы не будут перезаписаны при обновлении платформы.
:::

## Шаг 2. Установите модуль через админку

1. Зайдите в **Административную панель** сайта
2. Перейдите в раздел **Marketplace → Установленные решения** (или **Модули**)
3. Найдите в списке **SOK: Оформление заказа**
4. Нажмите **Установить**

Альтернативно — через PHP:

```php
\Bitrix\Main\Loader::includeModule('sok.order');
$module = new \Bitrix\Main\ModuleManager();
$module->install('sok.order');
```

## Шаг 3. Подключите шаблон компонента

Скопируйте шаблон компонента в папку шаблона вашего сайта:

```
/local/templates/ВАШ_ШАБЛОН/components/bitrix/sale.order.ajax/sok.order/
```

Затем укажите шаблон `sok.order` при вызове компонента на странице оформления заказа:

```php
$APPLICATION->IncludeComponent(
    'bitrix:sale.order.ajax',
    'sok.order', // <-- шаблон модуля
    [
        'PERSON_TYPE_ID' => '1',
        // ... остальные параметры
    ]
);
```

## Шаг 4. Проверьте установку

Откройте страницу оформления заказа на сайте. Если форма отображается корректно — установка прошла успешно.

::: warning
При возникновении ошибок проверьте лог Битрикс: **Настройки → Журнал событий**.
:::
