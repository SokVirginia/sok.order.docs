# Требования

Перед установкой убедитесь, что ваш сервер и сайт соответствуют следующим требованиям.

## Платформа

| Параметр | Минимум | Рекомендуется |
|---|---|---|
| 1С-Битрикс | 22.0 | Последняя стабильная |
| Редакция | Малый бизнес | Бизнес / Энтерпрайз |
| PHP | 7.4 | 8.1+ |
| MySQL | 5.7 | 8.0 |

## Модули Битрикс

Должны быть установлены и активны:

- `sale` — модуль интернет-магазина
- `catalog` — каталог товаров
- `iblock` — информационные блоки

## Требования к сайту

- На сайте настроен и работает **интернет-магазин**
- Компонент `bitrix:sale.order.ajax` **используется** на странице оформления заказа
- Есть доступ к файловой системе сервера (FTP/SSH или панель управления хостингом)

::: tip Для клиентов
Если вы не уверены, выполнены ли требования — передайте эту страницу вашему разработчику или обратитесь в команду SOK.
:::
